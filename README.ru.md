# OakGram

Хард-форк Margelet. Прошлый автор забил репозиторий кривым кодом, не умея даже составлять промпты. Мы выкинули весь мусор, переписали логику и сделали нормальный клиент с упором на приватность и кастомизацию.

По умолчанию: тёмная тема, розовый акцент (#FF4081), нулевая телеметрия, срезанные трекеры и защита от утечек.

### Приватность и безопасность

- **Run traffic via TOR**: перенаправление всего трафика через локальный SOCKS5 демон Tor / Orbot (`127.0.0.1:9050`).
- **Защищённый DNS (DoH)**: шифрование DNS-запросов через Mullvad, Quad9 или Cloudflare против провайдерских перехватов.
- **Duress PIN (Пин под принуждением)**: ввод альтернативного PIN мгновенно зачищает базы, кэши и гасит процесс.
- **Stealth Accounts**: скрытие выбранных аккаунтов, доступных только по секретному кодовому слову в глобальном поиске.
- **Защита от скриншотов (`FLAG_SECURE`)**: блокировка скриншотов, захвата экрана и скрытие превью в Recent Apps.
- **Анонимная пересылка**: пересылка сообщений без автора и подписей.
- **Авто-очистка кэша**: стирание временных расшифрованных файлов при уходе в фон.
- **Очистка EXIF**: срез GPS-координат, моделей камер и дат из фотографий без пережатия.
- **Anti-UTM**: вырезание рекламных параметров (`utm_*`, `fbclid`, `si=`, `igsh`, `ref` и др.) из ссылок.
- **Защита от утечки IP**: принудительный запрет прямого P2P в звонках.
- **Ghost Mode**: скрытие «печатает...», анонимные истории, чтение без серверной отметки.
- **Panic Wipe**: экстренная кнопка мгновенного удаления всех данных.
- **Anti-Delete**: сохранение удалённых собеседником сообщений локально на телефоне.
- **Изоляция плагинов**: файрвол сетевых вызовов для Python-скриптов.

### Кастомизация

- **Неограниченные закрепы**: закрепление любого количества чатов в папках и основном списке без лимита в 5 чатов.
- **Форматирование кода**: быстрые кнопки для `monospace` и многострочных блоков кода в поле ввода.
- **Скругление сообщений**: слайдер от 0dp (прямые углы) до 28dp (круглые).
- **Форма аватарок**: круглые, сквиркл или квадратные.
- **Чат**: отключение историй, скрытие кнопок ботов, скрытие селектора «Отправить от имени», отключение реакций по дабл-тапу, отправка по Enter.
- **Голосовые и медиа**: автопауза музыки при записи, подтверждение отправки голосовых, запись кружочков с задней камеры, ускорение до 3.0x.
- **Папки**: скрытие подписей папок, счётчики на вкладках, скрытие вкладки «Все чаты».

### Сборка

Сборка под Linux / WSL2 в один клик:

```bash
./build.sh
```

Или вручную:

```bash
git clone --depth=1 --recursive https://github.com/DrKLO/Telegram.git
cd Telegram
git apply /path/to/OakGram/patch/margelet.patch
cp -r /path/to/OakGram/java/* TMessagesProj/src/main/java/
./gradlew assembleAfatRelease
```

Результат: `TMessagesProj/build/outputs/apk/afat/release/TMessagesProj-afat-release.apk`
